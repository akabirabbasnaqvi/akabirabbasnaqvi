**Highlights:**

- Built a React and TypeScript monitoring dashboard
- Developed asynchronous FastAPI services with SQLAlchemy and PostgreSQL
- Implemented model registry, dataset profiling, and prediction-log ingestion
- Added PSI, KS, and categorical drift detection
- Designed a weighted model health scoring system from 0 to 100
- Added rule-based diagnosis and automated retraining recommendations
- Integrated Redis, Celery, Celery Beat, MLflow, DVC, and background job tracking
- Containerized services with Docker Compose and Nginx
- Added GitHub Actions CI, structured JSON logging, Ruff, and pytest
- Completed 14 automated tests with 61% test coverage
